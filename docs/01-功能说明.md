# 01 · 功能说明

一个基于 DOM 渲染的块（Block）结构协同编辑器：**多文档 + 分享链接**（编辑链接/只读链接，类腾讯文档），两个浏览器同时打开同一文档链接，一方的输入、修改、删除会实时出现在另一方；支持远程光标、块锁、在线用户、断线重连后的自动补发同步、**关页后未同步编辑恢复**、**快照恢复到任意历史版本**、**大纲导航**、明暗主题（首帧前应用，无闪烁）。v4 起完整适配手机浏览器（响应式）。v2 起带用户系统（注册/登录、用户名全局唯一）与 SQLite 持久化。

## 1. 运行方式

```bash
npm install        # 安装依赖（根目录执行，npm workspaces；Node ≥ 22）
npm test           # 全部 47 个测试（引擎/协议/认证/存储/多文档权限/评论/回收站 + 客户端模型与工具）
npm run build      # 构建前端产物 client/dist
npm start          # 启动服务器：http://localhost:3000
```

开发模式（前端热更新，Vite 5173 端口，/ws 与 /api 代理到 3000）：

```bash
npm run dev
```

数据保存在 `data/collab.db`（SQLite，首次启动自动迁移旧版 data/doc.json）。

### 页面结构（SPA 路由）
| 路径 | 页面 | 说明 |
|---|---|---|
| `/` | 文档首页 | 登录后：我的文档列表（新建/改名/删除）；未登录：登录引导。访客通过分享链接参与编辑 |
| `/d/:docId` | 编辑页 | **编辑链接**（docId 为 UUID，即编辑凭据）。是否可编辑取决于"仅创建者可编辑"开关 |
| `/r/:roToken` | 只读入口 | **只读链接**：实时查看他人编辑，整页禁编辑 |

**演示协同**：登录 → 新建文档 → 点"分享"复制链接 → 另一个标签页/浏览器打开。登录态按标签页隔离（sessionStorage），两个标签页天然是两个用户。

## 2. 功能清单

### 基础编辑
| 功能 | 操作 |
|---|---|
| 输入文本 | 直接键入；支持中文输入法（IME 组词期间不闪断） |
| 修改文本 | 选中替换、逐字修改 |
| 删除文本 | Backspace / Delete |
| 拆分块 | Enter（光标处拆为两个 Block，事务原子提交） |
| 合并块 | Backspace 于块首（并入上一块）；Delete 于块尾（吞并下一块） |
| 跨块移动 | 方向键在块边界自动跳转（上/下/左/右） |
| 多行粘贴 | 粘贴含换行的文本自动拆成多个块 |

### 协同能力
| 功能 | 说明 |
|---|---|
| WebSocket 实时同步 | 服务器为唯一权威，任何提交成功即广播给其他用户 |
| 远程用户光标 | 彩色光标线 + 名牌（名牌在光标移动后显示约 2 秒后淡出，避免遮挡；8 秒未更新变暗） |
| 在线用户 | 顶栏彩色头像 + 人数；心跳 5s，超时 15s 剔除 |
| Block / Block ID | 每块全局唯一 id（客户端生成 UUID）；悬停块右侧显示短 id |
| Block 锁 | 聚焦块即持锁（他人看到彩色边框 + "🔒 某某 编辑中"名牌）；失焦释放；TTL 15s 心跳续期，连接断开自动释放 |
| 强制块锁开关 | 顶栏"强制块锁"：开启后服务器**拒绝**他人对持锁块的写入（客户端同时将该块设为只读做前置拦截） |
| 乐观更新 | 本地键入立即显示，不等服务器确认；状态栏实时显示"待同步 N" |
| Transaction | 一次手势（如回车拆块 = 删尾 + 插块）打包为原子事务：全部成功或全部失败 |
| ACK | 每个事务有唯一 txId，服务器逐个确认并附最新版本号 |
| 断线重连 | 指数退避重连（0.5s→8s + 抖动）；横幅提示；期间编辑保留在本地 |
| 操作重试 | 在线确认超时 5s → 同 txId 重发（最多 5 次）；重连后统一对账补发 |
| 冲突处理 | 块级 CAS：不同块并发无冲突双双生效；同块并发后到者被拒后**自动变换合并重试**（详见 docs/04） |
| Undo / Redo | Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z；撤销以"逆操作事务"实现，天然同步给他人；打字按 800ms 合并为词级撤销单元 |
| **块类型（v2）** | 正文/标题一~三/无序列表/待办/代码块；三种输入方式见下表；待办块可点击勾选（双端同步）；列表回车自动续型、空列表回车转正文、非正文块块首退格转正文 |

### 块类型的输入方式（重要）

| 想要的效果 | 方式一：`/` 菜单 | 方式二：Markdown 快捷输入 |
|---|---|---|
| 标题一/二/三 | 空块输入 `/` → 选"标题一"（支持 `/h1` `/标题` 等别名过滤） | 输入 `#` + 空格（`##`、`###` 同理） |
| 无序列表 | `/列表` 或 `/list` | `-` + 空格（`*`、`+` 也可以） |
| **待办勾选框** | `/待办`、`/todo`、`/check` | **`[ ]` + 空格**（未勾选）；**`[x]` + 空格**（直接创建已勾选） |
| 代码块 | `/代码` 或 `/code` | 连续输入 ``` ``` |
| 转回正文 | `/正文` | 在块首按 Backspace |

- Markdown 触发只在**触发串独占整块**时生效（行首锚定），不会干扰正文中的 `#`、`-` 等字符；
- 勾选框本身不是文本字符，而是块属性：点击方框切换完成态（删除线样式），Ctrl+Z 可撤销；
- 菜单内：↑↓ 选择、Enter 确认、Esc 关闭，继续输入可按中文名/拼音/英文过滤。
| **用户系统（v2）** | 注册/登录/登出（scrypt 加盐哈希 + 会话 token）；访客模式零门槛；改名（全局唯一校验，重名明确报错）；用户颜色固定 |
| **数据库（v2）** | SQLite（node:sqlite）：users/sessions/docs/snapshots 四表，每次提交即落盘，重启零丢失 |
| **主题（v2）** | 明/暗双主题，跟随系统偏好，可手动切换并记住 |
| **多文档与分享（v3）** | 文档首页（新建/改名/删除，登录限定）；**编辑链接** `/d/:docId` + **只读链接** `/r/:token`；"仅创建者可编辑"开关（开启后他人打开编辑链接也是只读，服务器强制） |
| **快照恢复（v3）** | 快照查看器一键"恢复到此版本"——以 `doc.replace` 事务原子替换全文，**可撤销**，他人端实时同步 |
| **关页恢复（v3）** | 未确认编辑实时落 localStorage（按文档隔离），关页/崩溃后重开自动恢复并对账补发 |
| **大纲导航（v3）** | 右侧大纲栏实时生成（h1/h2/h3），点击平滑跳转，滚动高亮当前章节，可折叠 |
| **文档标题（v3）** | 编辑页顶部标题栏，创建者可改（REST PATCH），列表/浏览器标题同步 |
| **手机适配（v4）** | 响应式：头部换行转静态流式布局、触控目标加大（复选框 20px/按钮）、iOS 输入防聚焦缩放（16px）、"/"菜单窄屏钳制、模态纵向堆叠、状态栏/横幅/Toast 适配；`viewport-fit=cover` 支持刘海屏 |
| **主题无闪烁（v4）** | 明暗主题在 HTML 首帧前应用（head 内联脚本，防 FOUC）；切换瞬时生效（无颜色过渡，消除各元素变化不同步的闪烁感） |
| **块 ID 标识（v4）** | 悬停块右侧的 `#xxxx` 显示块 ID 前 4 位；悬停提示完整 ID，点击复制（块 ID 是操作锚定/光标定位/远程渲染的地址，调试与讲解用） |
| **远程选区高亮（v5）** | 他人选中文字时，你这边实时看到 ta 用户色的半透明选区色块（按行渲染）+ 选区终点光标——与远程光标互补，"看到对方正在引用哪段" |
| **全文搜索（v5）** | Ctrl+F 或 🔍：即时匹配、`n/N` 式跳转（Enter/Shift+Enter）、CSS Custom Highlight API 高亮（不动 DOM，不影响协同与光标；旧浏览器退化为仅跳转） |
| **块级评论（v5）** | 块旁 💬 气泡显示未解决数；右侧评论面板按块聚合线程、回复、标记解决；新评论 WS 实时推送（他人评论有 Toast + 角标）；点击线程标题跳转到块 |
| **Markdown 导出（v5）** | ⤓ 按钮：复制全文 Markdown 到剪贴板 / 下载 `.md` 文件（标题/列表/待办/代码块完整映射，有单测） |
| **只读申请编辑（v5）** | 只读用户点"申请编辑"：文档开放编辑时直接给"以编辑模式打开"入口；开启"仅创建者可编辑"时给可复制的申请文案 |
| **快捷键面板（v5）** | `?` 或顶栏按钮：10 条快捷键速查 |
| **回收站（v5）** | 删除的文档进回收站保留 7 天：首页可恢复或彻底删除，超期自动清理 |
| **快照对比（v5）** | 快照查看器支持"与当前对比"：按块对齐 + 行内字符级红绿 diff |
| 文档版本 | 顶栏状态显示当前版本 vN；每个成功事务 +1；状态栏实时字数统计 |
| Snapshot | 服务器每 50 个版本落一个快照文件（data/snapshots/vN.json） |
| 历史快照查看 | 顶栏"历史快照"按钮：列出快照、点击只读查看任意版本内容 |
| 持久化 | 服务器提交后防抖写入 data/doc.json，重启不丢 |

## 3. 五分钟演示脚本

1. **首页与登录**：A 标签页注册"小明" → 首页"＋ 新建文档"→ 进入编辑页（顶部标题可改）。
2. **分享**：点"分享"→ 复制**只读链接**给 B 标签页打开 → B 显示"👁 只读模式"徽标，整页禁编辑，
   但能实时看到 A 的输入与光标；再复制**编辑链接**给 B → B（访客身份）即可编辑，双向同步。
3. **仅创建者可编辑**：A 在分享面板勾选开关 → B 刷新编辑链接 → 变为只读；A 取消勾选 → B 恢复可编辑。
4. **块类型**：B 空块输入 `/待办` 或 `[ ] ` + 空格创建勾选框；`# ` 标题；A 端同步看到类型与勾选变化。
5. **大纲**：文档里有标题块时右侧出现大纲，点击跳转、滚动高亮。
6. **快照恢复**：编辑到 v50+ → "历史快照"→ 选版本 → "恢复到此版本"→ 全文替换且可 Ctrl+Z 撤销。
7. **断线重连**：Ctrl+C 停服务器 → 横幅提示、本地继续编辑 → `npm start` 重启 → 自动补发，双端版本一致。
8. **关页恢复**：停服务器 → 输入一段文字 → 关闭标签页 → 重启服务器 → 重新打开该文档 →
   未同步的文字自动恢复并补发（Toast 提示）。
9. **同块冲突**（自动化测试验证）：两人同时改同一段落后到者自动合并重试，双方输入都保留。

## 4. 已知限制（详见 docs/04/05/06/07）

- 撤销是本地线性撤销，不感知他人对同一块的修改（选择性撤销属研究级，见 docs/04 演进路线）；
- 同块并发依赖"块内微型变换"做合并体验，非严格 OT/CRDT（服务器 CAS + 拒绝重试兜底）；
- HTTP 未加 TLS（本地演示安全；公网部署前置 HTTPS，见 README）；块内富文本样式未做（Peritext 级）；
- `node:sqlite` 在 Node 24 为 experimental 标记（用量小、全参数化，可平滑替换）；
- 单机单进程（水平扩展路线见 docs/04）。
